Relational Database Development

수주잔고 산출을 위한 계약 관리 데이터베이스 구축

Role
경영기획팀 · 대표 직속 · 공시 업무 지원
Period
2021.05 — 2026.02
Tools
MS Access · VBA · Relational Database Design · SQL Query Design

Overview

공시자료에 기재하는 수주잔고 산출을 위해 계약 건별 상세 정보(금액, 기간, 상태 등)가 필요했으나, 이러한 정보가 체계적으로 기록되지 않아 산출할 때마다 원문서를 일일이 확인해야 했고 이로 인한 시간 소요 및 오류 리스크가 존재했습니다.

Approach

  • MS Access로 계약(Contract)—계약상세(Contract Detail) 테이블 간 1:N 관계형 데이터베이스 설계
  • 원계약/부속계약(갱신·변경) 이력을 계약 단위로 연결 관리할 수 있는 구조 구현
  • 회사명, 계약유형, 품목, 계약기간 등 조건별 검색 쿼리 및 조회 폼 구축

Result

실시간
계약 데이터 조회·집계를 통한 수주잔고 즉시 산출
자동화
공시자료 작성 시 수작업 집계 프로세스 제거
정합성 개선
소요시간 단축 및 데이터 정합성 개선
